# JavaTavern 全功能路线图

目标是在不复制参考项目源码、界面、文案或资源的前提下，完成一个可靠的原生 Android 角色聊天客户端。只有源码、测试、文档和可演示入口同时存在时才标记完成。

SillyTavern 功能对齐的详细差距分析、行为清单与分阶段实施计划见 [`docs/SILLYTAVERN_PARITY.md`](SILLYTAVERN_PARITY.md)——下面各里程碑里标记 ❌ 的项目大多能在那份计划里找到更细粒度的落地步骤。

## M1：聊天核心

- [x] 私聊、SSE 流式、停止生成和本地历史。
- [x] 图片输入与 OpenAI-compatible 多模态请求。
- [x] 消息复制、编辑、删除、回复引用、emoji 反应和重新生成。
- [x] 键集分页、FTS 搜索和上下文跳转。
- [ ] 持久化消息版本、左右切换与分支树。
- [ ] 回复整轮验收、原文查看、补丁修复与重试。

## M2：架构与多会话

- [x] `ChatRepository` 数据边界。
- [x] 私聊 `ChatViewModel + StreamSession` 流式生命周期。
- [ ] `SavedStateHandle` 与统一 screen state。
- [x] 基础群聊、成员管理、手动选择发言者和历史落库。
- [ ] 群聊 ViewModel、停止生成、`@` 提及和自动角色调度。
- [ ] 每角色多个聊天室、归档和删除保护。

## M3：Agent 与记忆

- [x] 本地只读指令和危险写操作确认、事务、审计。
- [x] 用户确认的角色长期记忆与长度受限的 Prompt 注入。
- [ ] 版本化 `AgentTool` 注册表、参数 schema、风险级别和幂等键。
- [ ] 创建角色、聊天室、世界书和配置修改工具。
- [ ] 会话摘要、记忆模板与受控记忆提案。
- [ ] Agent 运行记录、待确认项和中断后续作。

## M4：角色、世界书与预设

- [x] V2 JSON 基础字段和嵌入世界书导入。
- [x] PNG `tEXt` / 未压缩 `iTXt` 角色卡导入和头像提取。
- [x] 世界书位置、顺序、优先级、深度、概率和递归字段编辑。
- [x] 内置/自定义生成参数预设并写入请求。
- [ ] alternate greetings、example dialogue、压缩 `iTXt`、正则脚本和导出。
- [ ] 世界书条件组、命中解释和本地角色库。

## M5：创作与媒体

- [ ] 独立创意写作工作区、剧情存档和重置。
- [ ] 多图输入、相机直拍和素材相册。
- [ ] 图片生成 Provider、失败重试、复用和重新生成。
- [ ] 贴图管理、动态发布和 AI 评论。

## M6：数据、体验与性能

- [x] 系统深浅色主题适配。
- [x] 统一数据库和旧库保留式迁移。
- [ ] 版本化 ZIP 导入导出、冲突预览和原子恢复。
- [ ] Prompt/请求诊断、错误分类和 usage 统计。
- [ ] 无障碍、自定义壁纸和大屏布局。
- [ ] Macrobenchmark、万条消息、内存、耗电、弱网和 vivo 真机报告。
- [ ] 稳定签名、自动发布和升级验证。

## 发布规则

1. `main` 必须通过单元测试、lint 和 Debug 构建。
2. Preview 版本可以缺功能，不能把规划写成已实现。
3. 数据迁移失败必须保留旧数据，不能删库规避升级问题。
4. 远程服务使用用户自带密钥，项目不运营中转服务器。
5. 参考项目仅用于理解产品边界与开放格式，不复制受保护表达。
