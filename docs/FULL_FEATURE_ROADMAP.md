# JavaTavern 全功能路线图

目标是在不复制 AiChat 源码、界面、文案或资源的前提下，完成一个原生 Java Android 酒馆客户端。每项功能只有在源码、测试、文档和可演示入口同时存在时才标记完成。

## M1：聊天核心（进行中）

- [x] 私聊、流式输出、停止生成、本地历史。
- [x] 图片输入与 OpenAI-compatible 多模态请求。
- [x] 消息复制、编辑、删除、回复引用、emoji 反应。
- [x] 助手消息重新生成。
- [ ] 持久化消息版本、左右切换与分支树。
- [ ] 回复整轮验收、原文查看、补丁修复与重试。

## M2：架构与多会话

- [x] 以 `ChatRepository` 隔离角色、消息、Agent 审计和长期记忆存储。
- [ ] `ViewModel + Repository + SavedStateHandle`。
- [ ] 每角色多个聊天室、归档、重命名和删除保护。
- [ ] 群聊、多角色调度与 `@` 提及。
- [ ] 会话级模型、Prompt 预设和生成参数。

## M3：Agent 与记忆

- [x] 本地只读指令和危险写操作确认、事务、审计。
- [ ] 版本化 `AgentTool` 注册表、参数 schema、风险级别和幂等键。
- [ ] 创建角色、聊天室、世界书和配置修改工具。
- [x] 用户确认的角色长期记忆与长度受限的 Prompt 注入。
- [ ] 会话摘要、记忆模板导入导出与受控 Agent 记忆提案。
- [ ] Agent 运行记录、待确认项和中断后续作。

## M4：角色与世界书

- [x] V2 JSON 基础字段和嵌入世界书导入。
- [ ] PNG 角色卡元数据、alternate greetings、example dialogue 和导出。
- [ ] 世界书条件组、命中解释和条件概览。
- [ ] 本地角色库、标签搜索与可解释推荐。

## M5：创作与媒体

- [ ] 独立创意写作工作区、剧情存档和重置。
- [ ] 多图输入、相机直拍和素材相册。
- [ ] 图片生成 Provider、失败重试、复用和重新生成。
- [ ] 贴图分页、生成、去背景、切割和聊天室绑定。
- [ ] 动态发布、评论、摘要和私聊联动。

## M6：数据、体验与性能

- [ ] 版本化 ZIP 导入导出、冲突预览、原子恢复和完整性校验。
- [ ] 深浅色模式、无障碍、自定义壁纸和大屏布局。
- [ ] Prompt/请求诊断、上下文组成、响应错误分类和 usage 统计。
- [ ] Macrobenchmark、万条消息、内存、耗电、弱网和 vivo 真机报告。
- [ ] 签名发布、版本升级与 GitHub Releases。

## 发布规则

1. `main` 始终通过单元测试、lint 和 Debug 构建。
2. Preview 版本允许缺功能，不允许把规划写成已实现。
3. 数据迁移必须保留旧聊天，不能通过删库规避升级问题。
4. 所有远程服务均为用户自带密钥，项目不运营中转服务器。
5. 参考项目只用于理解产品边界和开放格式，不复制其受保护表达。
