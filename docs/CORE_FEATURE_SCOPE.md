# 核心功能取舍

## 产品定位

JavaTavern 不追求短期复制任何现有客户端。定位是：**原生 Android、可审计 Agent、移动端行为可解释的本地优先 AI 角色助手**。

## 当前核心

| 能力 | 状态 | 实现边界 |
| --- | --- | --- |
| 私聊 | 已实现 | RecyclerView、本地历史、ViewModel 流式状态、上下文窗口 |
| 基础群聊 | 已实现首版 | 成员管理、手动选择发言者、群聊 Prompt 和历史落库 |
| 流式输出 | 已实现 | OpenAI-compatible SSE、50 ms 合并刷新、停止和生命周期取消 |
| Agent | 已实现首个写工具 | `/clear` 确认卡、事务、结果和审计；尚无通用工具注册表 |
| 图片输入 | 已实现 | Photo Picker、后台压缩、私有存储、LRU 与视觉请求 |
| 角色卡 | 已实现首版 | V2 JSON、PNG `tEXt`/未压缩 `iTXt`、头像和世界书 |
| 世界书 | 已实现首版 | 关键词/常驻、位置、优先级、概率等字段和 Prompt 注入 |
| 生成预设 | 已实现首版 | 常用采样参数的内置、自定义、应用和删除 |
| 记忆 | 已实现受控版 | 仅用户确认的长期记忆，不允许模型自动无限写入 |
| 搜索 | 已实现 | 当前会话 FTS、结果列表和上下文定位 |
| 数据迁移 | 已实现首版 | 统一 SQLite，旧库迁移失败时回滚并保留源文件 |
| 性能证据 | 部分实现 | 有分页、缓存、节流和埋点；缺正式 benchmark 与真机报告 |

## 下一优先级

1. 群聊 ViewModel、停止生成、旋转恢复和 `@` 提及。
2. `SavedStateHandle`、统一 screen state 和数据库迁移测试。
3. 消息分支、Prompt 请求诊断和版本化备份恢复。
4. 通用 Agent 工具注册表、风险分级和结构化卡片 schema。
5. Macrobenchmark、弱网、内存、耗电和 vivo 真机验证。

## 暂缓

- 朋友圈动态、贴图生成和完整创意写作模式。
- 桌面版与复杂世界书节点连线编辑器。
- 多家图片生成服务和大规模在线角色库。

## 防止抄袭的约束

1. 不使用参考项目的名称、人物设定、页面结构、图标、文案和资源。
2. 只兼容公开数据格式和通用协议，独立实现解析、存储和交互。
3. Agent 采用“提案—确认—执行—审计”，写操作不由模型直接落地。
4. 以 Android 生命周期、隐私、安全和性能证据作为主要差异点。
