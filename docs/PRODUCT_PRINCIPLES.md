# Product Principles

## 1. The story comes first

The home screen should answer “where do I want to continue?” rather than “which AI feature do I configure?”. Model details belong in setup and advanced settings.

## 2. Local-first must be visible

Users should understand which data remains on-device and what leaves the device when a remote model is used. Privacy is product copy and behavior, not only encryption code.

## 3. Progressive disclosure

The default path exposes character, conversation, attachment, send, stop, retry, and search. Samplers, prompt diagnostics, world-book rules, and provider-specific fields stay one level deeper.

## 4. Destructive actions pause

Delete, overwrite, import replacement, and configuration changes must explain scope and require confirmation. Model text never bypasses local permission checks.

## 5. Recovery beats novelty

Draft preservation, retry, export, migration safety, and readable errors have higher priority than feeds, stickers, or decorative Agents.

## 6. Honest states

Use “正在连接”, “已停止”, “没有收到文本”, and actionable errors. Do not simulate certainty, emotions, or progress the app cannot verify.

## 7. Compatibility without copying

Support open character and chat formats where practical, but build an original Android information architecture and visual system.
