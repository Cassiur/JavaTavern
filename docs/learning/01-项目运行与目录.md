# 专题 01：项目运行与目录

## 目标

- 能从命令行和 Android Studio 构建运行。
- 能说出 `app/src/main` 下 Java、res 和 Manifest 的职责。
- 能定位首页、聊天页、设置页和入口 Activity。

## 关键路径

- `app/src/main/AndroidManifest.xml`：组件、权限和应用安全默认值。
- `app/src/main/java/com/zcz/javatavern/MainActivity.java`：角色首页。
- `app/src/main/java/com/zcz/javatavern/ChatActivity.java`：聊天主流程。
- `app/src/main/java/com/zcz/javatavern/SettingsActivity.java`：模型配置。
- `app/src/main/res/layout`：XML 页面与列表项。
- `app/build.gradle.kts`：SDK、Java 版本和依赖。

## 构建命令

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-17.0.18.8-hotspot'
cd D:\study\android\JavaTavern
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

## 验证标准

- 8 个测试通过。
- `assembleDebug` 成功。
- `lintDebug` 成功。
- APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 实践

把应用标题改成你确定的项目名称，重新构建并在模拟器看到修改。
